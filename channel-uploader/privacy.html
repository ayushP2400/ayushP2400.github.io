Privacy Policy

Channel Uploader ("the tool") is a private tool used only by its owner, Ayush Pathak, to upload videos to his own YouTube channels. This policy explains what data the tool touches.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

What data the tool accesses

  • The signed-in channel's ID and title, to confirm the upload goes to the right channel.
  • The video file, title, description, tags, thumbnail, playlist and schedule that the owner supplies for his own videos.

The tool does not access any other user's or channel's data, does not collect analytics, and does not use cookies or tracking.

How data is used, stored and shared

  • Data is used only to upload and set up the owner's own videos.
  • OAuth tokens are stored only on the owner's computer, in files readable only by the owner. No data is stored on any server run by the tool.
  • No data is shared with, sold to or disclosed to any third party.

Revoking access and deleting data

Access can be revoked at any time through the Google security settings page at https://security.google.com/settings/security/permissions. To delete stored data, revoke access there and delete the local token files; the tool keeps no other copy. Questions or deletion requests: ayush.pathak021@outlook.com.

Changes
